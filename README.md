## 📋 Prérequis

- Flutter SDK (version 3.7.0 ou supérieure)
- Dart SDK (inclus avec Flutter)
- Android Studio / Xcode (pour la compilation mobile)
- Un émulateur ou un appareil physique

## ⚙️ Installation

```bash
# 1. Cloner le repo
git clone https://github.com/medaziz701/Drink_ordering_app.git
cd Drink_ordering_app

# 2. Installer les dépendances
flutter pub get

# 3. Lancer le projet
flutter run
```

## ✨ Fonctionnalités

- **Menu interactif** : Navigation fluide à travers la liste des boissons disponibles
- **Détails produits** : Affichage détaillé avec images, prix et descriptions
- **Carrousel d'images** : Navigation visuelle entre les différents produits
- **Sélecteur de taille** : Choix de la taille de boisson souhaitée
- **Toggle température** : Sélection entre boissons chaudes et glacées
- **Sélecteur de quantité** : Ajustement facile de la quantité commandée
- **Splash screen** : Écran d'accueil animé avec logo
- **Design moderne** : Interface utilisateur soignée avec animations fluides
